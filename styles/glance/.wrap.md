# wrap config — glance

Inferred during the 2026-07-21 wrap and kept. Correct it when it drifts;
a wrong config is worse than none, because it stops the next pass from
looking.

## Canonical locations

- index: `CLAUDE.md` — the "What this repo is" + "Architecture" sections
  must match what is on disk. There is no separate index file.
- lessons: `CLAUDE.md` — the `## Traps` section. Repo-scoped lessons go
  here; there is no fleet-wide file above this repo.
- evidence: `docs/` — human-tested findings. **Never purge, never
  regenerate from a model.** `docs/glyph-legibility.md` records what a
  human read on a real terminal; no model can reproduce that judgement,
  which makes it the least replaceable thing in the repo.
- skills: n/a — this repo *is* a prompt, it does not host skills.
- decisions: n/a — no ADR directory. A cross-cutting decision goes in
  the commit body, which is why commit bodies here are long.
- journal: n/a — nothing is deployed to an environment.

## Verification commands

- blocking: `./build.sh` — regenerates both surfaces and lints
  `prompt.md` + the two generated files. Must exit 0.
- blocking: `git status --short` after `./build.sh` must be empty —
  a non-empty status means a generated file was edited directly instead
  of `prompt.md` or a `.tmpl`.
- advisory: `npx markdownlint-cli CLAUDE.md README.md 'docs/*.md'` —
  these are outside `build.sh`'s scope and drift unnoticed. MD013
  line-length violations in `CLAUDE.md` are known and pre-existing;
  do not reflow the file to chase them.

## Disposable zones

Effectively none — this repo does not accumulate scratch. Already
excluded and not to be re-proposed for deletion:

- `.personal/`, `.claude/` — gitignored
- `.impeccable/hook.cache.json` — in `.git/info/exclude`
- `.DS_Store` — global gitignore

## Commit conventions

- format: `<type>: <the conclusion, lowercase>` — no scope, no ticket
  ref (this repo has no tracker)
- types in use: `feat`, `docs`, `chore`
- The subject states what became true, not what was edited.
- Bodies carry the reasoning, since there is no ADR directory.
- No `Co-Authored-By` and no generated-with footer.

## Notes for the next pass

- Editing `claude-code/glance.md` or `claude-ai/glance-style.md`
  directly is always a mistake — they are generated. Edit `prompt.md`
  for shared rules, the matching `.tmpl` for per-surface wording.
- A rule in `prompt.md` that seems to condemn something a repo file
  does deliberately is usually the rule being too narrow. See
  `## Traps` in `CLAUDE.md`.
- The Claude.ai surface has no install automation: after a prompt
  change the style must be re-pasted by hand. A wrap cannot verify it.
