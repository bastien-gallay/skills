# wrap config — skills-hub

## Canonical locations

- index: README.md (plugin table) and registry.json — `node docs/build.mjs` regenerates docs/index.html, docs/og-template.html, docs/og.png; never hand-edit those
- lessons: CLAUDE.md of the plugin concerned (`plugins/<plugin>/CLAUDE.md`)
- decisions: `plugins/<plugin>/docs/architecture/` (F-*.md design notes); no ADR directory
- journal: `plugins/<plugin>/CHANGELOG.md`, section Unreleased
- personal notes and briefs: `.personal/` (ignored via .git/info/exclude, never committed)
- tracker: none (GitHub issues unused)

## Verification commands

- blocking: `git ls-files -z '*.md' | xargs -0 npx --yes markdownlint-cli2@0.24.0` (the CI command)
- blocking: `claude plugin validate .`
- blocking: the client-term scan over HEAD and the branch's commit messages; the term list stays private (`.personal/wrap/client-terms.txt`, never committed)
- advisory: `gh run list --branch main --limit 6` (fails with a TLS error inside the sandbox: run outside it)

## Disposable zones

- `.personal/**/scratch*`
- `.DS_Store`

## Commit conventions

- format: a sentence stating the conclusion, no type prefix
- one idea per commit; stage explicit paths (a hook refuses staging everything)
- release tags: `<plugin>/vX.Y.Z`
