# wrap configuration — show-me

## Canonical locations

- index: `README.md`, the "What it holds" table must match
  `skills/show-me/**/*.md`
- entry point: `README.md`, `## Status` (version, date, what the ✅ rest on)
- lessons: this repo *is* a skill; a rule goes in `skills/show-me/SKILL.md`, a
  render finding in `references/render-targets.md` with a numbered source
- decisions: no ADR directory, no CHANGELOG. The history is the commit
  subjects, one release per commit: `show-me <version>: <the conclusion>`
- journal: none
- tracker: none. The hub `bastien-gallay/skills` carries the published
  version in `registry.json`.

## Verification commands

- blocking: `markdownlint-cli2 README.md "skills/show-me/**/*.md"`
- blocking: `jq -e . hooks/hooks.json .claude-plugin/plugin.json`
- blocking: `sh -n hooks/show-me-reflex.sh`, then pipe-test it:
  `printf '{"prompt":"montre-moi"}' | sh hooks/show-me-reflex.sh` prints one
  JSON line; `printf '{"prompt":"lance les tests"}' | sh hooks/show-me-reflex.sh`
  prints nothing

## Disposable zones

- `.impeccable/`, `.claude/` — gitignored tooling state

## Commit conventions

- format: `show-me <version>: <the conclusion>`, GPG-signed
- push: `main` only

## Notes

- ⛔ Local branch `private-history` carries client details. Never push it,
  never copy from it.
- A version bump touches `.claude-plugin/plugin.json` and the `## Status`
  line, then a hub PR on branch `chore/show-me-<version>`: edit
  `registry.json`, run `node docs/build.mjs`. A rename also touches the
  hub's `.claude-plugin/marketplace.json` and its `README.md` row (they carry
  no version).
- The hook greps the whole stdin JSON. It also fires when a relayed subagent
  report quotes a trigger word (seen 2026-10-12 on a refuter report quoting
  « montre-moi »). Not ticketed: the cost is one extra skill load.
- Named `show` until 0.3.6 (renamed 2026-10-12). An old reference to `show`
  in another repo is a stale pointer, not a second skill.
- GPG signing fails inside the sandbox. A failed attempt can leave
  `~/.gnupg/public-keys.d/pubring.db.lock` owned by a dead PID, which times
  out the next signed commit: check the PID, then remove the lock.
